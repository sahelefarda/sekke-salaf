# تحلیل ارزندگی اوراق سکه

ابزار تحت وب برای تحلیل و ارزش‌گذاری اوراق مبتنی بر سکه با در نظر گرفتن:

- ارزش بازخرید تضمینی
- ارزش اعمال و دریافت سکه
- YTM (بازده تا سررسید) هر سناریو
- اسپرد نسبت به نرخ بهره بدون ریسک
- ارزش منصفانه اوراق
- تشخیص ارزندگی یا گران بودن ورقه

این پروژه کاملاً استاتیک است و بدون نیاز به سرور روی GitHub Pages اجرا می‌شود.

این ابزار دو سناریوی اصلی را بررسی می‌کند:

سناریو اول: بازخرید تضمینی

در این حالت دارنده ورقه از اختیار اعمال استفاده نمی‌کند و اوراق را بر اساس ارزش تضمینی بازخرید می‌کند.

سناریو دوم: اعمال اوراق

در صورتی که ارزش روز سکه بیشتر از ارزش تضمینی باشد، دارنده می‌تواند اوراق را اعمال کرده و سکه دریافت کند.

ارزش نهایی ورقه برابر است با:

Max(
ارزش تضمینی،
ارزش اعمال
)


بنابراین حتی اگر قیمت بازار ورقه از ارزش تضمینی بالاتر باشد، در صورت برتری ارزش اعمال، ورقه ممکن است همچنان ارزنده باشد.
